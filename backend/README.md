# hrashwa dirga backend

node.js backend api for the hrashwa dirga application.

## tech stack

- node.js
- express
- mongodb with mongoose
- firebase admin sdk
- cloudinary
- jwt authentication

## setup

install dependencies:

npm install

create a .env file with required environment variables.

## run

development:

npm run dev

production:

npm start

## notes

this service handles authentication, game logic, admin operations, and configuration.
