# hrashwa dirga

hrashwa dirga is a fun react native mobile application project built using the react native.

## getting started

make sure your development environment is set up for react native before running the project.

## start metro

from the root of the project, start the metro server:

npm start  
or  
yarn start

## run the app

open a new terminal and run the app on your platform.

### android

npm run android  
or  
yarn android

### ios

install pods if this is your first time or if native dependencies changed:

bundle install  
bundle exec pod install

then run:

npm run ios  
or  
yarn ios

## development

edit the file app.tsx to start making changes. the app will reload automatically when you save.
